# udaan – Rural Women Artisans & Skilled Sisters Marketplace

An empowering marketplace connecting rural women artisans with global conscious buyers, and local skilled sisters with neighborhood households.

## 🚀 Key Features

- **Dynamic "Hire Skilled Sisters" Marketplace**:
  - Live verified sister profiles with exact UI cards (Boutique Tailoring, Mehendi Artist, Home Cook & Tiffin, Beauty & Skincare, Yoga, Tutoring, etc.).
  - Interactive like counter and distance proximity radius filters (within 3km, 5km, 10km).
  - Category filters, search bar, and sorting.
- **Urban Company Style "Enroll as a Skilled Sister" Onboarding**:
  - Step-by-step partner self-enrollment modal with real-time card preview.
  - Set custom visiting rates (₹/visit), specific service packages, and working availability.
  - Dynamic instant addition to the live listing with persistent local state.
- **"Hire Her" Doorstep Appointment Booking Engine**:
  - Select service, date & time slot, enter doorstep address, and confirm booking.
  - Generates instant booking confirmation reference (e.g. `UD-94821`).
  - Track active visits in "My Bookings" dashboard.
  - Direct WhatsApp and in-app chat inquiry.
- **Authentic Handmade Crafts Store**:
  - Jaipur blue pottery, Chanderi sarees, Dokra brass art, tribal mirror work.
  - Shopping cart and checkout simulator with direct-to-artisan support.

## 💻 Tech Stack

- **React 18** + **Vite**
- **Tailwind CSS**
- **Lucide Icons**
- **Canvas Confetti**

## 🛠 Local Setup & Development

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev

# 3. Build for production
npm run build
```

## 🌐 Deploy to Vercel

1. Push this repository to GitHub:
```bash
git init
git add .
git commit -m "feat: Dynamic Hire Skilled Sisters platform with partner enrollment & booking"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/udaan.git
git push -u origin main
```
2. Go to [vercel.com](https://vercel.com), click **Add New Project**, import your GitHub repository, and click **Deploy**.
